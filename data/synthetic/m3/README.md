# M3 检索诊断样本

`retrieval_diagnostics.jsonl` 是开发阶段的检索诊断样本，用于观察中文词项改写、相近错误码、下划线字段名、版本号条件、信息缺失和语料无答案时的候选来源表现。

这不是独立测试集，也不用于生成向量、训练、发布指标或替代人工验收。每条记录的来源标注只依据 `../v2/historical_cases.jsonl` 中已有案例：`relevant_source_ids` 表示可用于理解或核查当前问题的历史线索，未必能直接确定结论；`answer_available` 表示当前语料是否有可直接套用的答案证据；`distractor_source_ids` 表示主题、词项或错误码相近但条件不适用的案例。因缺信息而无法确诊时，相关来源仍可保留在 `relevant_source_ids`。

`group_id` 把近重复查询聚在一起，便于比较检索器是否因为词形、错误码近似或缺少关键条件而改变结果。全部记录的 `label_status` 为 `pending_review`，需要用户审阅后才能作为正式评估依据。

`cached_queries.jsonl` 另保存 5 条 M0/M2 历史查询的原文及精确缓存路径，用于零新增付费调用的 Dense/BM25/Hybrid 对比。查询向量仍在被 Git 忽略的原缓存中，未复制或修改。相关性标签也全部待审；API 超时查询只将 006/007 作为相关核查线索，旧检索曾返回的 008 属于错误码干扰，不能因被召回就标为相关。正式评测不得将这些开发样本或同组改写当作独立测试样本。
