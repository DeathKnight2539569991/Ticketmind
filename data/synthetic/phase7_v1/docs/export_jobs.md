# 异步导出与下载
## 作业状态
synthetic=true。本文仅定义虚构产品“示例协作台”的离线演示规则。

queued、running、failed、completed 是不同状态。等待页面不刷新不等于失败，running 可只读核对作业 ID 和状态，不保证完成时刻。failed 查脱敏错误及快照；completed 可核对文件元信息。
## 链接与元信息
链接失效不同于生成失败。completed 的旧链接不可用，可只读核对作业、元信息及当前权限。重新生成前确认当前项目/字段权限、过滤快照和时间范围，不保证原文件恢复。下载失败但链接状态或权限未知时先补事实。
## 失败重建与人工核验
失败先核对错误、范围、权限，由审核人员决定重建。离职账号取回数据、敏感导出、疑似丢失或恢复承诺交授权人工。Agent 不恢复、不借用离职身份、不保证文件已找回。缺作业 ID/状态不能猜失败阶段。
