# 正式导入作业
## 预览与正式提交
synthetic=true。本文仅定义虚构产品“示例协作台”的离线演示规则。

预览通过仅代表当前只读解析和校验。正式提交是独立写入，产生作业 ID 和状态。尚未提交可核对模式、目标项目及范围；提交后报错先核对状态与逐行报告，不凭页面报错判断写入为零。
## append 与 replace 范围
append 只追加通过校验的新记录，提交前核对目标项目、新记录范围及模式，不保证全成功。replace 会覆盖目标范围，需有权限的人确认范围与审批。客户自称获批不构成授权；Agent 不执行覆盖，也不把页面过滤当写入目标范围。
## 作业结果与重复键
record_id 为目标项目内记录键。重复键和部分失败须查作业结果、逐行错误、成功及失败行；明确重复键报告可支持只读核对输入键和既有记录，不自动重试写入。报错不证明所有行未写入，重试风险须人工确认。
