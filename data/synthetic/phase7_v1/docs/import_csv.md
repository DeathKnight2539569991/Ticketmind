# CSV 解析与显示
## UTF-8 与显示差异

CSV 按 UTF-8 解析，可带 BOM。分别核对 UTF-8 文本查看器、平台预览和桌面软件表现。原文和预览正常，仅桌面双击乱码，可保留副本在桌面软件按 UTF-8 打开核对，不据此断言文件损坏。原文也异常时先补生成方式和脱敏字符样例。
## 分隔符与 CSV 引号
文件按预览所选分隔符拆列；核对实际逗号或分号。含分隔符字段须用双引号包围，内部双引号用两个双引号转义。描述值含逗号且未包围会导致错列。仅预览未提交时可保留原件、修正副本后重新预览样例行。
## 排错与安全边界
乱码先补三处显示对照；错列先补预览分隔符和原始行，不都归为编码损坏。文件疑似密钥或敏感名单交安全和权限人员，不索取密钥，不关闭扫描，不保证未泄露。已提交需核对作业结果，不能沿用只读预览结论。
