# 导入字段与预览
## 必填字段与精确表头
synthetic=true。本文仅定义虚构产品“示例协作台”的离线演示规则。

必填字段固定为 record_id 和 summary，可选 project_id、created_at、internal_note。字段名区分大小写，空格参与精确匹配；Summary 或 summary 尾空格均不等于 summary。未正式提交且格式问题已核实，可保留原件、修正副本后重新预览。预览只读，不代表正式写入。
## 列映射与样例行
显式映射允许来源别名 ticket_no 到 record_id、issue_text 到 summary；别名不自动识别。只有映射面板明确显示目标且样例值对应正确，才可核对后继续预览，不能仅看别名断定缺列。重复目标映射需核对冲突。预览出现其他项目敏感列，交有权限人工核验访问边界。
## 预览错误定位
收集原始表头、预览列位置、脱敏样例行及错误位置，区分表头不匹配、值校验和分隔符错列。只说必填列缺失不足以确定原因。尚未提交且证据明确时可修正副本重新预览；强制跳过校验写入交人工核验，不提供绕过方式。
